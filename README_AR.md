# تعلّماتي الأولى — PWA

## المعاينة محليًا
افتح `index.html` في متصفح حديث لتجربة معظم الأنشطة. قد يمنع المتصفح بعض ميزات PWA عند فتح الملف مباشرة.

## التثبيت كتطبيق PWA
للتثبيت والعمل دون إنترنت يجب نشر الملفات عبر HTTPS:
1. ارفع محتويات هذا المجلد إلى استضافة ثابتة تدعم HTTPS، مثل GitHub Pages.
2. افتح رابط الموقع في Chrome على Android.
3. اختر من القائمة «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».

## المميزات
- تضمين ملف الكتاب الأصلي `book.pdf` وعرضه من داخل الصفحة.
- تمارين اختيار الحروف وربط الصور بالكلمات ومراجعة عامة.
- لوحة رسم تعمل باللمس لتتبع الحروف.
- حفظ النتائج باستخدام localStorage.
- manifest وservice worker للتثبيت والتخزين المؤقت.

## تنبيه
هذه نسخة تجريبية؛ أنشطة الصور والكلمات أمثلة تعليمية عامة وليست مستخرجة حرفيًا من كل درس في الكتاب. ملف PDF الأصلي مضمّن كما أُرسل.
